# 爆竹大师 · 十夜驱祟 🎆

一款以李畋爆竹传说为灵感、讲述小灵龙指引匠人驱邪纳祥的原创网页益智游戏。旋转引线、自动引燃爆竹、点亮烟花、赢得乡民喝彩，完成十夜历练，成为「爆竹大师」。

> **版本：V1.3「烟火新绘」｜可试玩的独立非官方作品**。本游戏并非《Rocket Mania! Deluxe》的官方移植或授权版本，不包含原版商业游戏的代码、图像和音乐。

## 🎮 游玩

**[在线开始游戏](https://u0axuan.github.io/baozhu-master/)**

离线游玩：下载 [index.html](./index.html) 并直接用 Chrome、Edge 或 Safari 打开。无服务端、无联网游戏素材依赖，画面、角色、动态音效与配乐均由浏览器程序生成。

## 玩法

- **引线连通后自动点燃**，不需要手动点火。
- 可旋转未锁定的管道；待燃和燃烧中的管道锁定，不能再次操作。
- 连发爆竹、升级爆竹和触发道具可提高隐藏积分；用围观人群与灯火表现进度，而非数字分数。
- 十夜主线：第 1 夜为 5×5，第 2 夜为 7×7，第 3 夜起为 9×9。
- 第 3 夜开始逐渐出现新道具；通过关卡自动升级；后期含随机天命增益与减益。
- 音乐会响应燃烧、连发以及灯笼临近熄灭的压力；移动端支持触控和兼容设备的振动反馈。

## 技术

纯 HTML / CSS / JavaScript / Canvas / Web Audio；**所有游戏运行时素材通过程序生成**，不需要安装依赖或下载外部贴图和音频。支持 PC 和手机屏幕自适应。

开发调试使用本地测试接口（URL 参数 `?test`），不会联网上传用户数据。

## 当前限制

- 小灵龙的程序化绘制仍未达到角色设定图的精度；原版动画的逐帧量化对照尚未完成。
