# V1.3 测试记录与限制

此前迭代完成了主要 Chromium 自动化规则断言，覆盖前 3 关棋盘尺寸、道具解锁与生效、十夜状态推进、大师结局、自动点火、待燃与燃烧锁定、粒子数量上限及多视口检查。迭代期间报告了 103 项主要断言通过。

**说明：** 这些是开发阶段的自动化结果，**不等于已在实际安卓手机完成兼容性或性能测试**。其中十关通关流程使用测试接口推进，而非真人逐关游玩；原有测试脚本没有全部放入本次网页目录。

本次发布前另外检查了单文件 HTML 不依赖外部资源、未发现外部 URL/密钥引用，并通过 Node.js JavaScript 语法检查。

建议公开反馈重点关注：移动端流畅度、燃烧中锁定反馈、爆竹与烟花演出时间差、音乐与触觉强弱、十关平衡及 UI 遮挡问题。
